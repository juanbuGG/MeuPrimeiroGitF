## Questionário

### 1. Qual é a diferença entre Working Directory, Staging Area e Repository?

Working Directory é onde fazemos as alterações nos arquivos.
Staging Area é onde colocamos os arquivos que serão incluídos no próximo commit.
Repository é onde ficam os commits e o histórico do projeto.

### 2. Qual é a diferença entre git commit e git push?

O `git commit` salva as alterações no repositório local.
O `git push` envia os commits para o repositório remoto no GitHub.

### 3. É possível realizar vários commits antes de executar um git push?

Sim. Podemos fazer vários commits localmente e depois enviar todos de uma vez com o `git push`.

### 4. Por que é interessante realizar commits pequenos e descritivos?

Porque facilita entender o histórico e saber exatamente o que foi alterado em cada etapa.

### 5. O que acontece com os commits locais quando ainda não executamos o git push?

Eles ficam salvos apenas no repositório local e ainda não aparecem no GitHub.

### 6. Como verificar, pelo GitHub, se os commits foram enviados corretamente?

Podemos acessar o repositório no GitHub e verificar o histórico de commits.
